## Comparison with frozen production candidates

The frozen production training cache contains 152,065,947 pairs at link recall
0.9558922623. The diagnostic recomputed top-6 contains 45,331 fewer pairs
(about 0.030%) and slightly different recall. Production can reuse a legacy
token-channel cache, while this diagnostic recomputes all channels. This is a
known execution-path difference, not a proven complete explanation of the
count difference; exact pair-level equivalence has not been established.
Interpret depth gains against the diagnostic's own baseline. The raw report's
statement that top-6 mirrors production describes the integer-search policy,
not identical frozen pair membership.

Any future candidate expansion must union deeper results with the frozen
production candidates, preserving all existing pairs. Reuse the original index,
candidate and feature artifacts; compute only missing artifacts where possible.
Expanded rank-dependent features need explicit versioning. Expanded scoring and
grouped validation are required before treating this diagnostic as submission
evidence. Training-memory and saved-output fit must be measured for the expanded
pool: a 3.49-fold candidate increase is not covered by the previous model-fit
resource approval, and the diagnostic's small RSS does not describe model fitting.
